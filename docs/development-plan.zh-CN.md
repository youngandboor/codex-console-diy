# Codex Console DIY 并行开发计划

更新日期：2026-07-26

## 核心原则

项目按“功能兼容最终能够验证成功”推进产品设计，不等待协议工作全部结束才开始键盘
设计。可逆的设计和样机工作并行进行；只有 PCB 投产、电池定型和最终外壳加工等
不可逆、成本较高的动作需要等待对应验证门槛。

## 2026-07-26 Alpha 快速推进决策

USB、BLE、外接多按键和双传输自动切换已经实机通过。项目不再等待矩阵、RGB、
旋钮、摇杆和电池分别完成面包板验证，而是直接设计一块集成 PCB Alpha 和配套
3D 打印外壳，用同一套样品完成剩余验证。该决策接受一次 PCB 改版的成本，但不降低
电池、USB 和首次上电的安全检查。

- Rev A 同时包含完整输入、20 颗 RGB、PowerPath、燃料计和电池机械包络。
- 第一次只做 5 片 PCB、2 套外壳；先无电池限流上电，再接电源模块，最后接受保护电池。
- 板载麦克风只预留且默认不贴，避免 USB Audio/BLE Audio 风险进入主样品关键路径。
- 发板门槛改为原理图/ERC/DRC/封装/3D/极性审查完成，不再要求全部子系统先过面包板。

## 三条并行主线

| 主线 | 当前工作 | 阶段输出 |
| --- | --- | --- |
| 功能与固件 | BLE/USB HID、按键矩阵、旋钮、摇杆、RGB、电池策略 | 可重复测试的固件和验证记录 |
| 产品与结构 | 1:1 布局、操作间距、键帽和手感、灯光扩散、外壳与装配 | 尺寸图、外壳样件和交互决策 |
| 电路与 PCB | 原理图、功耗预算、器件选型、封装、布局布线和可制造性 | 原理图 Rev A、PCB Rev A 和生产 BOM |

三条主线共享同一份接口基线：ESP32-S3-N8R8、12 个命令/Agent 键、编码器按压、
双轴摇杆、20 颗可寻址 RGB、BLE 和原生 USB、单节锂电池。

## 同步里程碑

| 里程碑 | 功能与固件 | 产品与结构 | 电路与 PCB |
| --- | --- | --- | --- |
| M0 架构冻结 | 双传输和 RPC 框架 | 控件数量及分组 | GPIO 和电源框图 |
| M1 单控件验证 | USB/BLE 单按键 | 1:1 纸面/打印布局 | 原理图框架和器件库 |
| M2 完整台架 | 矩阵、旋钮、摇杆、20 RGB | 控件手感、间距、扩散样件 | 原理图 Rev A、PCB 外形草案 |
| M3 电源样机 | 充电、续航、切换和休眠 | 外壳 Rev A、内部堆叠 | PCB Layout Rev A、生产 BOM |
| M4 集成 Alpha | 全功能回归 | 完整装配样机 | 首批 5 片 PCB 投产 |
| M5 Beta | 稳定性和异常恢复 | 人体工学与灯效微调 | PCB/外壳修订 |

## 下单门槛

- 1:1 布局、纸模、3D 外壳草模和原理图可以立即开始。
- 通用样品件可以在第二批购买，用于比较手感、高度和灯光扩散。
- PCB 可以提前完成到 Rev A，但 USB 与 BLE 均未通过时不投产。
- 电池可以先完成容量和堆叠设计，实际型号在内部空间和峰值功耗确定后下单。
- 最终 EC11 轴高、摇杆高度、键帽和卫星轴由结构样机决定。
- 集成 Alpha 可在协议和双传输通过后投产，但必须完成正式电气与机械设计审查；
  输入、灯光和电源的剩余风险由首批 5 片 Alpha 承担。

## 第二批中的设计样品

第二批不再只有面包板功能件，同时采购以下低风险设计样品：

| 样品 | 建议数量 | 要验证的问题 |
| --- | ---: | --- |
| MX 透明轴试轴包 | 线性/段落/有声各 3 个 | 最终手感和噪声 |
| MX 透光空白键帽 | 1U 十二个、2U 一个 | 间距、透光、标签方案 |
| 2U 卫星轴 | 板装和 PCB 装各 1 套 | Mic 键结构和装配难度 |
| 凯华 MX 热插拔轴座 | 20 个 | PCB 封装和可维护性 |
| EC11 编码器 | 15 mm、20 mm 轴高各 1 个 | 旋钮露出高度和手感 |
| 编码器旋钮 | 直径约 15/18/20 mm 各 1 个 | 手指空间和外观比例 |
| 摇杆样品 | PS2 全尺寸、PSP 紧凑型各 1 个 | 行程、精度、安装高度 |
| 半透明材料小样 | 乳白亚克力或半透明 PETG，1-3 mm | RGB 扩散和亮点控制 |
| 数显卡尺 | 0-150 mm | 实物封装和外壳尺寸测量 |

第二批样品的任务是做选择，不要求所有样品进入最终产品。选择结果要记录到硬件
规格和 PCB BOM，避免后续仅凭商品名称替换尺寸不兼容的零件。
