# Rev A 发板与打印检查表

这份清单把“设计完成”和“可以花钱生产”分开。所有 `P0` 项通过后才允许下单
PCB；结构件可以先打印低成本草样，但不得据此购买真电池。

## P0：PCB 下单前必须关闭

- [ ] KiCad 原理图完成，所有器件型号、阻容值和电源时序已填写。
- [ ] ERC 无未解释错误；保留的警告逐条写明原因。
- [ ] 所有封装按原厂尺寸图和一件实物二次核对，尤其是 USB-C、EC11、摇杆、
  热插拔轴座、2U 卫星轴和滑动开关。
- [ ] USB D+/D- 按板厂真实四层叠层计算 90 Ohm 差分阻抗，不使用猜测线宽。
- [ ] ESP32-S3 天线净空满足原厂数据手册；净空区上下层无铜、无电池、无螺钉。
- [ ] BQ24074 充电电流根据最终电芯规格设定，热焊盘和散热铜满足原厂建议。
- [ ] 3.3 V 与 5 V 电源分别完成最坏负载、启动、关断和反灌电流检查。
- [ ] DRC 无未解释错误；Gerber、钻孔、板框和阻焊文件用独立查看器复核。
- [ ] 先生产 5 片，其中只贴 2 片；第一片不装电池，限流电源分电源域上电。

## P0：外壳打印前必须关闭

- [ ] 以 100% 比例打印 `layout.svg`，实物摆放确认手距、2U Mic 和摇杆行程。
- [ ] 核对 G Pro 3.0 Brown、EC11、摇杆、卫星轴、USB-C 和开关的实际高度。
- [ ] 外壳螺柱与 PCB 焊盘、轴座、电池、天线净空无干涉。
- [ ] 2U 定位板开口和卫星轴开口使用所购实物尺寸，而不是通用估计值。
- [ ] USB 插头完全插入时不顶壳；电源开关可操作且不会被误触。
- [ ] 电池托盘无锐角，电芯与焊点之间有刚性绝缘片，且可无损拆卸。
- [ ] 先打印 2 套：一套便宜材料装配验证，一套在修正后验证灯光扩散。

## 仍可在 Alpha 后修改

- 轴体触感与键帽图标；
- 外壳表面处理、颜色和边缘灯扩散材料；
- 板载 PDM 麦克风是否装配；
- 后续独立 2.4 GHz 接收器版本。

这些项目不应阻塞 Rev A，但任何影响 PCB 封装、开孔或射频净空的修改都必须重新跑
ERC、DRC 和 3D 干涉检查。
